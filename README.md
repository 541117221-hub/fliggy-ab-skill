# ab-experiment-report

通用 AB 实验数据分析与报告生成技能，适用于 QoderWork Agent。

支持两种分析模式：有实验 ID 的 AB 实验模式、无实验 ID 的人群包对比模式。自动从 FDP 查询数据、计算漏斗指标、执行双样本比例 Z 检验，生成交互式 HTML 实验报告。

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 双模式分析 | AB 实验模式（有/无实验 ID）+ 人群包对比模式 |
| 多数据源支持 | FDP 自动查询 / ODPS SQL / 历史报告提取 / 截图 OCR / 文本 / CSV |
| 漏斗指标计算 | L2D（列表页引导）、D2O（详情页转化）、L2O（整体转化效率） |
| 统计显著性检验 | 双样本比例 Z 检验，输出 Z 值 / P 值 / 显著性标签 |
| 功效分析 | 未达显著时，计算达到显著所需样本量/天数 |
| 人群维度拆分 | 支持 88VIP（`is_88_vip`）等维度的一次性拆分分析 |
| 目标人群过滤 | 支持诸葛人群 ID 过滤，只看特定人群在实验中的转化 |
| 推全外推估算 | ΔL2O × 平均 PV，支持间夜换算（酒店业务） |
| 交互式 HTML 报告 | Chart.js 趋势图 + 飞猪黄色主题（#FFC900） |

## 安装

### 前置依赖

必须安装并授权 `fliggy_data_mcp` MCP Server：

1. 打开 https://code.alibaba-inc.com/trip-platform/fliggy-data-skills
2. 按文档完成 `fliggy_data_mcp` 的下载和 OAuth 授权
3. 授权完成后，在 QoderWork 中确认 MCP 状态正常

### 安装 Skill

**方式一：Git 克隆（推荐）**

```bash
cd ~/.qoderwork/skills/
git clone https://github.com/541117221-hub/fliggy-ab-skill.git ab-experiment-report
```

**方式二：手动下载**

将仓库中的 `SKILL.md` 放入以下路径：

```
~/.qoderwork/skills/ab-experiment-report/SKILL.md
```

安装完成后，在 QoderWork 中提及"AB 实验分析"等关键词即可触发本 skill。

## 使用流程

### Step 1：选择分析模式

触发后 skill 会先询问分析模式：

- **A - AB 实验模式**：有分组 ID，可选填实验 ID 和目标人群 ID
- **B - 人群包对比模式**：无实验 ID，直接对比两个人群包

### Step 2：确认实验参数

**AB 实验模式**必填/选填参数：

| 参数 | 必填/选填 | 示例 |
|------|----------|------|
| 实验 ID | 选填 | 808（有则提供，无则留空） |
| 对照组分组 ID | 必填 | 3876, 3870 |
| 实验组分组 ID | 必填 | 3871, 3877 |
| 目标人群/诸葛人群 ID | 选填 | 86416（菲住会员人群包） |
| 人群维度拆分 | 选填 | 88VIP（`is_88_vip`） |
| 观测指标口径 | 必填 | 曝光 UV → IPVUV → 下单 UV |
| 日期范围 | 必填 | 2026-05-08 至 2026-05-13 |

**人群包对比模式**参数：

| 参数 | 示例 |
|------|------|
| 对照组人群包 ID | 147778 |
| 实验组人群包 ID | 129656 |
| 日期范围 | 2026-05-30 至 2026-06-01 |

### Step 3：获取数据

数据源优先级（自动降级）：

```
FDP 自动查询
  → ODPS SQL（FDP 引擎故障时）
    → 用户提供历史报告
      → 截图 OCR / 文本输入 / CSV/Excel
```

FDP 不可用时，skill 会询问用户选择降级方案，**不会自动降级**。

### Step 4：生成报告

完整报告包含七章 + 实验背景：

| 章节 | 内容 |
|------|------|
| 0. 实验背景与策略 | 策略机制说明（如 88VIP 降门槛） |
| 1. 数据汇总 | 日均 UV + 日均比率 + 绝对提升 |
| 2. 显著性检验 | Z 检验（累计样本）+ 功效分析 |
| 3. 增量估算 + 推全外推 | 三种口径并行 + 间夜换算 |
| 4. 每日趋势可视化 | Chart.js 折线图 + 柱状图 |
| 5. N 日留存（可选） | 复购/复访 + 业务解读 |
| 6. 核心发现 | 策略与人群效果匹配等洞察 |
| 7. 结论与建议 | 5 条建议，含价值量化 |
